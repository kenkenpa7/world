# 🗺️ プロジェクト計画書 (Project Plan)

## プロジェクト概要
海外旅行者向けに、世界各国の「リアルな両替・決済事情」を提供する専門情報サイト。
圧倒的な利便性とデザイン性（Bento UI・ダークモード）を武器に、ユーザーからの確固たる信頼（E-E-A-T）を獲得することを目的とする。

## 技術スタック（モノレポ構成）
- **フロントエンド**: Next.js (App Router), Tailwind CSS, Framer Motion
- **バックエンド（CMS）**: Sanity
- **インフラ**: Vercel (フロント), Sanity Content Lake (データ)
